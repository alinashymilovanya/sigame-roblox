# Тесты SIGame Lounge

## Оффлайн-симуляция сервера (`sim_server.luau`)

Прогоняет реальный `GameServer.server.luau` в обычном Luau CLI (без Roblox Studio),
подставляя заглушки для `game`, `Instance`, `RemoteEvent`, игроков и сигналов.

**80 проверок** покрывают:
- вход игроков и создание комнаты;
- открытие вопросов (правильный ответ скрыт от игроков, виден ведущему);
- отправку ответов и оценку ведущим (защита от двойной оценки и читерства);
- завершение вопроса и оглашение ответа;
- вопросы с выбором ответа;
- модерацию (мут), «пит» (яму), выкидывание из игры;
- заказ чая/кофе/кальяна и мемные предметы с кулдауном;
- поиск по каталогу (оффлайн-заглушка), предложение паков и голосование;
- установку демо-пака;
- устойчивость к мусорным данным и выходу игроков.

### Запуск

1. Встрой актуальный исходник сервера в тест (Luau CLI не умеет читать файлы):
   ```
   python tests/embed_server.py
   ```
2. Запусти симуляцию:
   ```
   .tools\luau\luau.exe tests\sim_server.luau
   ```

Ожидаемый финал: `RESULT: 80 checks, 0 failures` / `STATUS: PASS`.

> Если менял `GameServer.server.luau`, сначала перегенерируй `_server_source.luau`
> через `embed_server.py`, иначе тест проверит старую версию.
