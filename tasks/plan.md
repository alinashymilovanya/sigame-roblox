# План реализации SIGame Lounge

## Архитектура

- один Roblox-сервер — одна комната;
- сервер Roblox хранит игровое состояние и проверяет права ведущего;
- каталог — отдельный HTTP-сервис, который принимает исходный `.siq`, читает Steam Workshop и отдаёт нормализованный JSON;
- медиа проходят через manifest/asset pipeline, а не загружаются в UI как случайные URL.

## Что проверено автоматически

- **80 проверок** оффлайн-симуляции сервера (`tests/sim_server.luau`) — вся игровая логика.
- **7 тестов** бэкенда каталога (`catalog/tests/test_catalog_service.py`).

## Что НЕ проверено (блокеры для игры с друзьями)

| Шаг | Статус |
|---|---|
| Публикация опыта в Roblox | ❌ placeid=0, автопубликация из Studio не сработала |
| Реальный multi-client playtest (Studio Play, 2–3 игрока) | ❌ не выполнен |
| Внешний каталог доступен из Roblox (HTTP + туннель) | ⚠️ туннель Cloudflare временный, URL в Config устаревает |
| Загрузка медиа (картинки/звук из паков) | ⚠️ только через asset manifest, не проверено вживую |

## Риски

| Риск | Влияние | Митигирование |
|---|---:|---|
| Roblox не показывает внешние URL-медиа | Высокое | asset manifest и контролируемая публикация ассетов |
| Пак использует редкий тип вопроса | Среднее | безопасный fallback и предупреждение импорта |
| Внешний каталог недоступен | Среднее | demo pack + кэш последнего каталога (реализовано) |
| Мемное медиа нарушает права/модерацию | Высокое | пресетные оригинальные эффекты и allowlist |
| Studio/Rojo отсутствуют на машине | Среднее | исходный проект + отдельная установка toolchain (готово) |

## Ближайший путь к игре сегодня вечером

1. Открыть `.tools/SIGameLounge_Final.rbxl` в Roblox Studio.
2. Опубликовать через **File → Publish to Roblox** (плагин `tools/SIGamePublishPlugin.rbxmx` добавляет кнопку).
3. В Studio: **Test → Clients and Servers → 2–3 игрока → Start** для проверки мультиплеера.
4. Демо-пак работает без интернета и бэкенда — можно играть сразу.
