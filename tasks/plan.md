# План реализации SIGame Lounge

## Архитектура

- один Roblox-сервер — одна комната;
- сервер Roblox хранит игровое состояние и проверяет права ведущего;
- каталог — отдельный HTTP-сервис, который принимает исходный `.siq` и отдаёт нормализованный JSON;
- медиа проходят через manifest/asset pipeline, а не загружаются в UI как случайные URL.

## Этапы

### Фаза 1: Контракт и вертикальный срез

- [ ] Реализовать модель нормализованного пака и импортёр `.siq` v4/v5.
- [ ] Создать Roblox-проект Rojo с сервером комнаты и демонстрационным паком.
- [ ] Добавить экран входа с выбором роли «Игрок» или «Ведущий».
- [ ] Создать классическое поле и поток выбора вопроса.

### Checkpoint 1

- [ ] Локальный сервис импортирует тестовый `.siq`.
- [ ] Сервер Roblox поднимает комнату и отдаёт игрокам единое состояние.
- [ ] Ведущий может открыть вопрос и завершить его.

### Фаза 2: Ответы и каталог

- [ ] Добавить текстовые ответы, карточки вариантов и быстрые кнопки.
- [ ] Добавить проверку ведущего и очки.
- [ ] Добавить поиск каталога, предложение пака и режим голосования.

### Checkpoint 2

- [ ] Multi-client сценарий «ведущий + 2 игрока» проходит без рассинхронизации.
- [ ] Пак из каталога запускается в игре.

### Фаза 3: Lounge и мемные действия

- [ ] Собрать мультяшную кальянную-лаунж и рассадку.
- [ ] Добавить официанта, напитки и визуальные заказы.
- [ ] Добавить предметы с cooldown и модерацию ведущего.

### Checkpoint 3

- [ ] Игрок не может обходить cooldown или права ведущего.
- [ ] Ведущий может временно ограничить или отправить игрока в яму.

## Риски

| Риск | Влияние | Митигирование |
|---|---:|---|
| Roblox не показывает внешние URL-медиа | Высокое | asset manifest и контролируемая публикация ассетов |
| Пак использует редкий тип вопроса | Среднее | безопасный fallback и предупреждение импорта |
| Внешний каталог недоступен | Среднее | demo pack + кэш последнего каталога |
| Мемное медиа нарушает права/модерацию | Высокое | пресетные оригинальные эффекты и allowlist |
| Studio/Rojo отсутствуют на машине | Среднее | исходный проект + отдельная установка toolchain |

## Открытые решения

- где публиковать игру: личный аккаунт или Roblox-группа;
- какие именно паки пользователь даст для теста;
- нужен ли постоянный публичный каталог или достаточно каталога для друзей;
- какие медиа можно загружать в Roblox после проверки прав.
